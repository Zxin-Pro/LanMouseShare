# LanMouseShare · 局域网键鼠共享

把两台 Windows 电脑变成一台：一套鼠标键盘，两块屏幕，鼠标从这边屏幕边缘直接划过去就到了另一边，不用按任何热键，用起来就像一台电脑接了两个显示器。

- 主电脑插着鼠标键盘，叫 **主机**
- 另一台什么都不用插，叫 **副机**
- 两台电脑在同一个局域网里，程序通过 TCP（默认端口 24800）传鼠标键盘动作

## 特性

| 能力 | 说明 |
| --- | --- |
| 边缘自动切换 | 鼠标碰到屏幕边缘就过去，**不需要热键**，划回来也一样 |
| 屏幕布局 | 副机在 右侧 / 左侧 / 上方 / 下方，带偏移像素微调对齐 |
| 鼠标共享 | 移动、左键、右键、中键、侧键、垂直滚轮、水平滚轮 |
| 键盘共享 | 可开关，转发按键与组合键，用扫描码发送（游戏里也能用） |
| 强制返回 | `Ctrl+Alt+Home` 把光标拉回本机（可选热键，只在开键盘共享时生效） |
| 断线保护 | 副机掉线立刻把光标收回本机，绝不让光标留在对面 |
| 防粘键 | 断线或停止时自动补发「抬起」事件，不会卡住某个键 |
| 检查更新 | 内置 GitHub Release 检查，一键打开下载页 |
| 系统托盘 | 关窗口只是最小化到托盘，托盘菜单可切换角色、检查更新、退出 |

## 支持的系统

- Windows 7 SP1（需要手动安装 .NET Framework 4.8，见 [部署与安装](docs/部署与安装.md)）
- Windows 10
- Windows 11

技术栈：C# / WPF / **.NET Framework 4.8** / 编译为 AnyCPU（32 位和 64 位都能跑）。

> 为什么不用 .NET 8？因为 Windows 7 装不了。这个项目的第一条硬约束就是 Win7 SP1 必须能用，所以只能选 .NET Framework 4.8。

## 快速开始

两台电脑都要做：

1. 下载 Release 里的 zip，解压到任意目录（**不要放在中文路径下的深层目录**，省得惹麻烦）
2. 双击 `LanMouseShare.exe`。程序需要管理员权限，**每次启动都会弹 UAC**，点「是」——全局钩子和模拟输入都需要这个权限
3. 主机的「共享」页：角色选 **主机**，填一个连接密钥（随便一串字符，两台电脑必须一样），点「开始共享」
4. 副机的「共享」页：角色选 **副机**，填**同一个连接密钥**，「主机 IP」填主机的局域网地址（主机上点「复制本机 IP」就能拿到），点「开始共享」
5. 两边都显示已连接之后，到「屏幕布局」页把副机的位置设成和实际摆放一致（右边 / 左边 / 上边 / 下边），需要的话调一下偏移像素
6. 现在把鼠标往那个方向推出屏幕边缘试试

第一次运行时 Windows 防火墙会弹窗问是否允许，选**允许**（主机必须放行 24800 端口，副机不用）。

详细步骤和排查见 [使用手册](docs/使用手册.md)。

## 从源码构建

需要 .NET Framework 4.8（Windows 10/11 自带；Win7 要装）和 MSBuild（随 Visual Studio 或 .NET Framework 一起装）。

```powershell
# 编译（默认 Release）
powershell -ExecutionPolicy Bypass -File tools\build.ps1

# 自动验收：自检 13 项 + 回环联调 19 项
powershell -ExecutionPolicy Bypass -File tools\smoke-test.ps1

# 打包成可分发 zip
powershell -ExecutionPolicy Bypass -File tools\package.ps1
```

也可以直接用 Visual Studio 打开 `LanMouseShare.sln`——项目是经典的非 SDK 格式 csproj，VS 2017 及以上都能打开。

## 命令行开关

| 开关 | 作用 |
| --- | --- |
| `--selftest=N` | 跑 N 秒自检后自动退出（0=通过，2=失败），结果写进日志 |
| `--nettest=M` | 在本机回环地址上跑 M 毫秒超时的联调自检后自动退出，**不装钩子、不动真实鼠标** |
| `--updatetest` | 真的去 GitHub 拉一次 Release 信息验证检查更新链路，然后自动退出 |
| `--host` / `--client` | 指定启动角色 |
| 无参数 | 正常启动图形界面 |

## 数据放在哪

- 配置：`%LOCALAPPDATA%\LanMouseShare\config.json`
- 日志：`%LOCALAPPDATA%\LanMouseShare\logs\LanMouseShare-yyyymmdd.log`（按天分割）

日志只记录连接状态、屏幕切换、错误，**不记录你按了什么键**。

## 已知限制

- **UAC 安全桌面**（那个全屏的提权提示）出现时钩子和输入注入都会失效，鼠标键盘会留在原机器上。这是 Windows 的设计限制，任何用户态程序都绕不过去。
- 第一版**只支持单显示器**，多显示器的接口预留了但没实现。
- **剪贴板共享和文件拖拽**也预留了接口，第一版不做。
- Windows 7 上 DPI 感知只能做到系统级，不能做每显示器 DPI。

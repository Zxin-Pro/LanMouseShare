# LanMouseShare 使用手册

> 适用版本：1.0.5.0 · 平台：Windows 7 SP1 / Windows 10 / Windows 11
> 仓库：<https://github.com/Zxin-Pro/LanMouseShare>

## 1. 这个软件干什么

一句话：**让两台 Windows 电脑共用一套鼠标键盘，用起来就像一台电脑接了两个显示器。**

主机上那套鼠标键盘照常用，光标推到靠副机那一侧的屏幕边缘，不用按任何热键就自动划到副机屏幕上；从副机屏幕的边缘再划回来，又回到主机。副机不需要额外插任何东西。

| 你想要的 | 实际怎么操作 |
| --- | --- |
| 鼠标去副机 | 把光标推到两块屏幕贴合的那一侧边缘，继续推，光标就过去了 |
| 鼠标回主机 | 从副机贴着主机那一侧的边缘继续往外划 |
| 键盘在副机打字 | 光标在副机时直接打（需要打开「同时共享键盘」） |
| 强制把光标收回本机 | `Ctrl + Alt + Home`（可选热键，见第 6 节） |
| 彻底退出程序 | 托盘图标右键 →「退出(&X)」 |

## 2. 两个角色：主机与副机

同一个程序，两台电脑都要装。区别只在「这台电脑有没有插鼠标键盘」。

| | 主机 | 副机 |
| --- | --- | --- |
| 是什么 | **接了鼠标键盘的那台** | **没接鼠标键盘的那台** |
| 你人在哪 | 通常坐在主机前 | 副机只放屏幕 |
| 职责 | 装全局钩子，负责判定「光标该去哪」并把动作转发出去 | 收指令，用它自己的电脑把鼠标键盘动作「放」出来 |
| 要不要填主机 IP | 不用（它是被连接的一方） | **要**，填主机的局域网 IP |
| 角色可以换吗 | 可以，随时换 | 可以，随时换 |

两台电脑的角色是在「共享」页的单选按钮里选的，改完立刻生效。

## 3. 开始之前

1. 两台电脑在**同一个局域网**里（同一个路由器/交换机下，能互相 ping 通）。
2. 两台电脑都装好 LanMouseShare，并且都能正常启动。**程序每次启动都会弹 UAC 提权提示，这是设计如此**（全局键鼠钩子和模拟输入必须要管理员权限），点「是」即可。
3. 两台电脑都放行防火墙（**主机必须放行 24800 端口**，副机不用，详见[部署与安装](部署与安装.md)）。
4. 两台电脑的屏幕摆放就是真实的物理摆放，心里先确认一下：副机在主机的哪一侧。

## 4. 首次使用：六步走

两台电脑都启动 LanMouseShare，然后按顺序做：

### 第 1 步：两边填同一个「连接密钥」

在「共享」页的**连接密钥**里填一串字符。

- 两台电脑必须**完全一致**，大小写敏感。
- 可以点右边的「随机」按钮生成一串，然后想办法抄到另一台（微信给自己发一条就行）。
- 密钥只是用来做握手认证的，不会明文发送；密钥不一致时连接会直接被拒绝。

### 第 2 步：副机填主机 IP

副机在「共享」页把**主机 IP** 填成主机的局域网地址。

**怎么查主机 IP（两种办法，任选）**：

1. 在**主机**上点「共享」页主机 IP 那一行的 **「复制本机 IP」** 按钮，程序会把主机当前的局域网地址填进输入框；选中复制后发到副机去填。
   - 注意：这个按钮是「把本机地址填到这个框里」，在主机上按才有意义。
2. 在主机上打开命令行（Win+R 输入 `cmd`），执行：

   ```
   ipconfig
   ```

   找到正在用的那块网卡的「IPv4 地址」，形如 `192.168.1.23`。
   - 优先选 `192.168.x.x` / `10.x.x.x` / `172.16~31.x.x` 这类内网地址。
   - 如果有 VPN 虚拟网卡、虚拟机网卡，别选它们。
   - 「共享」页下方的提示文字本身就写着「本机局域网地址：…」，那是程序自己探测出来的结果。

### 第 3 步：选角色

- 主机：选 **主机 —— 鼠标键盘接在这台电脑上（副机的输入由它转发）**
- 副机：选 **副机 —— 这台电脑不接鼠标键盘，接收主机发来的输入**

### 第 4 步：主机先点「开始共享」

主机在「共享」页点 **「开始共享」**。此时主机进入监听状态，等副机连过来。

### 第 5 步：副机再点「开始共享」

副机在「共享」页点 **「开始共享」**，它会主动去连主机的 24800 端口。

两边都连接成功后，界面下方的状态栏和「日志」页会显示已连接；「诊断与更新」页的「运行环境」里也能看到当前角色、连接状态和副机分辨率。

### 第 6 步：设置屏幕布局（别跳过）

到 **「屏幕布局」** 页，按实际摆放设置副机的位置，然后就可以把鼠标推过去试了。

## 5. 屏幕布局怎么设

### 5.1 选方向

「屏幕布局」页最上面是四个单选按钮：

| 选项 | 什么时候选 | 鼠标从哪过去 |
| --- | --- | --- |
| 右侧 | 副机摆在主机的右手边 | 主机屏幕右边缘 |
| 左侧 | 副机摆在主机的左手边 | 主机屏幕左边缘 |
| 上方 | 副机摆在主机正上方 | 主机屏幕上边缘 |
| 下方 | 副机摆在主机正下方 | 主机屏幕下边缘 |

> **底线：主机和副机的屏幕排列必须和实际摆放一致。** 设反了，鼠标会往错的方向跑 —— 你往右推，光标却从左边跑掉，或者干脆过不去、过不去又回不来。装机后第一件事就是把这一项对准。

界面上还有一句提示：**要在副机界面上选「主机在左侧」，在主机界面上选「副机在右侧」，两边互为镜像，方向才会一致。** 拿不准就照着这句话两头对一下。

### 5.2 调「沿边偏移 (px)」

偏移用来对齐两台电脑的**屏幕错位**（比如副机的桌面比主机低一截，鼠标划过去会「跳」一下高度）。它的方向是沿贴合边移动：

| 摆放 | 偏移的含义 | 怎么调 |
| --- | --- | --- |
| 副机在右侧 / 左侧 | 把副机整体**上下**挪 | **副机比主机低，就填正数**；副机比主机高，就填负数 |
| 副机在上方 / 下方 | 把副机整体**左右**挪 | 副机比主机靠右，就填正数；靠左就填负数 |

调整方法：

1. 先在「屏幕布局」页下方的 **「布局预览」** 图上看清楚两台屏幕的相对位置（预览图上会画两个方框，标着「主机」和「副机」，下面还有一行文字摘要）。
2. 一次只改一个值，改完立刻把鼠标推过去试。
3. 差一点点就 ±10 像素地微调，直到鼠标从主机边缘划过去时**接缝高度对得上**、不会突然跳。

### 5.3 「回程守卫 (px)」（一般不用动）

同一页还有一个**回程守卫 (px)**，默认 4，作用是防止鼠标在两块屏幕交界处来回横跳：从副机划回主机时，必须在边界附近再多走这么多像素才生效。除非你确实遇到「在边缘反复横跳」，否则保持默认值。

## 6. 键鼠的日常操作

### 6.1 鼠标：碰边缘就走，不需要热键

- 光标推到**靠副机那一侧**的屏幕边缘，继续推 → 到副机。
- 从副机屏幕**贴着主机那一侧**的边缘继续往外划 → 回主机。
- 中间的移动、左键、右键、中键、侧键（X1/X2）、垂直滚轮、水平滚轮都会跟着过去。

### 6.2 强制返回本机：Ctrl + Alt + Home

副机卡住、或者你只是想立刻把控制权拿回来时，按 `Ctrl + Alt + Home`，光标会被强行收回主机。

- **这个热键只在开启「同时共享键盘」时生效**（它靠键盘钩子识别）。只共享鼠标时按了没反应，属正常。
- 另外「共享」页上还有一个 **「强制鼠标回本机」** 按钮，鼠标点得到的时候用它更快。

### 6.3 「同时共享键盘」什么时候开

建议：**先只开鼠标，用着稳定了再开键盘。**

- 第一次装好，先不勾「同时共享键盘（鼠标共享稳定后再开）」，把移动、点击、滚轮、划来划回都试顺。
- 确认鼠标稳定后再勾上它。此时光标在副机时，主机的按键会被拦下来发给副机（**主机自己就收不到这些键了**，这是设计行为）。
- 关掉开关时，按键**留在本机**，程序不会静默吞键。
- 键盘共享还有个附带好处：按 `Ctrl+Alt+Home` 可以直接收回光标。

### 6.4 两个额外的实用按钮（「共享」页）

| 按钮 | 用途 |
| --- | --- |
| 测试：把副机鼠标移到 (100,100) | 让副机光标跳到它自己屏幕的 (100,100)。副机「没反应」时用它快速判断链路通不通 |
| 强制鼠标回本机 | 立刻把光标收回主机，等价于 `Ctrl+Alt+Home` |

### 6.5 其他勾选项

| 选项 | 说明 |
| --- | --- |
| 同时共享键盘（鼠标共享稳定后再开） | 见 6.3 |
| 断线后自动重连（每 3 秒重试） | 网络抖动、副机重启后自动恢复连接，建议保持开启 |
| 程序启动时自动开始共享 | 程序一运行就自动进入共享状态，不用每次手点「开始共享」 |
| 启动时自动检查更新 | 启动 3 秒后去 GitHub 查一次 Release，有新版会提示 |

## 7. 系统托盘与退出

**关掉主窗口不会退出程序**，只是隐藏到托盘（右下角通知区域），共享继续跑。这是设计如此。

需要打开界面时，双击托盘的 LanMouseShare 图标，或者右键选「显示主窗口(&S)」。托盘菜单里还有：

| 托盘菜单项 | 作用 |
| --- | --- |
| 显示主窗口(&S) | 把窗口调回前台 |
| 以主机模式开始共享(&H) | 不改界面设置，直接以主机身份开始 |
| 以副机模式开始共享(&C) | 直接以副机身份开始 |
| 停止共享(&T) | 停止共享，鼠标键盘完全还给本机 |
| 把光标收回本机(&R) | 等价于「强制鼠标回本机」 |
| 检查更新(&U) | 手动查一次新版本 |
| 打开配置目录(&F) | 打开存放配置和日志的文件夹 |
| **退出(&X)** | **真正结束程序**（推荐用这个） |

**怎么才算真正退出程序：** 用托盘菜单的 **「退出(&X)」**，或者主窗口右下角的 **「退出」** 按钮。直接点窗口右上角的 × 只是最小化到托盘。

## 8. 常见问题排查

排查时优先看两个地方：**「日志」页**（有「自动滚动到最新」「清空显示」「打开日志文件」）和 **「诊断与更新」页的「运行环境」**（列着当前角色、连接状态、DPI 感知、架构、权限等）。

日志文件在：`%LOCALAPPDATA%\LanMouseShare\logs\LanMouseShare-yyyymmdd.log`（按天分割）。日志**只记录连接状态、屏幕切换和错误，不记录你按了什么键**。

### 8.1 连接不上

按顺序查：

1. **密钥不一致**：两边的「连接密钥」必须一字不差（注意大小写和首尾空格）。日志里会出现认证被拒的记录。
2. **主机 IP 填错**：副机的「主机 IP」必须是主机当前的局域网地址；主机换了网络（比如从有线换到 Wi-Fi、或换了路由器）IP 会变，要重新填。
3. **不在同一网段**：副机 `ping 主机IP` 试试。ping 不通就先解决网络，别折腾软件。
4. **主机没先点「开始共享」**：主机是监听的一方，先它后副机。
5. **防火墙拦了 24800**：见 8.5。
6. **端口被占**：如果主机 24800 被别的程序占用，可以在两边把「TCP 端口」改成别的值（比如 24801），**两台必须改成同一个**。
7. **两边都选了同一角色**：一边主机一边副机，别都选主机。

### 8.2 鼠标划到边缘过不去 / 卡在边缘

- **最常见原因是布局设反了或没设**。到「屏幕布局」页把方向改成实际摆放，一头一尾镜像确认（见 5.1）。
- 只在**一个方向**过不去：检查那块边缘是不是被别的程序占用了（比如某些游戏、远程桌面窗口会锁光标）。
- 如果副机从没连上过，主机不知道副机的分辨率，出于安全考虑**不会穿越**（否则光标会落到不存在的位置）。先看日志确认有没有连上。
- 划过去了但感觉「贴着边缘不动」：先把鼠标移开边缘一点点再推，或者用「强制鼠标回本机」。

### 8.3 鼠标跳 / 不跟手

- **偏移没调对**：鼠标过去时高度对不上就是典型症状，见 5.2。先在「布局预览」上看清楚再动手。
- **两台分辨率不同**：这是支持的。程序按比例换算，主机划满一整屏 = 副机划满一整屏，手感一致。
- **网络慢**：无线网络丢包、或两台机器隔着楼层，会有明显延迟。优先用有线，或者靠近路由器。
- **高回报率游戏鼠标**：程序会把移动帧就地合并（只保留最新位置），按键和滚轮绝不合并，正常情况下不会因为鼠标上报率高而卡。若确实卡，试着把主机的杀毒实时防护里的「网络扫描」放行本程序。

### 8.4 副机没反应

按顺序查：

1. 副机自己点了「开始共享」没有？副机是主动连接的一方，不点不会连。
2. 「诊断与更新」页的「运行环境」里连接状态是什么？两边都看一遍。
3. 在主机按 **「测试：把副机鼠标移到 (100,100)」**。副机光标跳了 = 链路通，问题在坐标/布局；不跳 = 链路没通或副机被拦。
4. **副机程序是不是以管理员身份运行的？** 每次启动都要点 UAC 的「是」。副机没提权时，向高权限窗口注入输入会失败。
5. **键盘不生效但鼠标正常**：主机上「同时共享键盘」没勾。注意这个开关在主机上设置（副机界面里会提示「本机是副机，键盘共享开关在主机上设置，本机跟随主机」）。
6. **副机上有粘键**（一直按住 Ctrl、或者某个键一直触发）：点「停止共享」再「开始共享」；正常路径下程序在停止和断线时都会补发「抬起」事件。
7. **正卡在 UAC 提权窗口或锁屏**：见 8.7。

### 8.5 Windows 防火墙弹窗 / 端口被拦

**一般是碰不到这个问题的**：主机点「开始共享」时程序会自己用 `netsh advfirewall` 把入站放行规则建好（域 / 专用 / 公用三档），日志里能看到「防火墙放行：已自动添加规则」。Win10 / Win11 对带管理员清单又主动监听的进程，经常一声不吭就把入站包丢掉，两边日志都看不出问题，所以程序不指望那个弹窗。

如果 Windows 还是弹窗问是否允许 LanMouseShare 访问网络 —— **选「允许」**（勾上专用网络）。

规则没建成功（比如程序不是以管理员身份跑的），就在**主机**上手动放行 24800 端口，图形界面或命令行都可以，详见[部署与安装](部署与安装.md)。**只有主机需要放行，副机是主动连接的一方。**

### 8.6 杀毒软件 / 安全软件拦截

本程序会做两件让安全软件敏感的事：**装全局键鼠钩子**和**模拟输入（SendInput）**。正规杀毒软件通常只是提示，但要**允许**，否则会出现「能连上但副机没反应」这种最难查的症状。

处理办法：

1. 把 LanMouseShare 的整个安装目录加入**信任区/白名单**。
2. 如果杀软按行为拦截（HIPS / 主动防御），把「键盘记录」「模拟点击」相关的拦截放行。
3. 某些「游戏加速器」「输入法增强」「鼠标驱动宏工具」也会抢钩子，冲突时暂时退出它们再试。
4. 公司电脑上的终端管控软件（EDR）可能直接禁止装钩子，这种情况需要找 IT 加白名单，程序侧绕不过去。

### 8.7 UAC 弹窗 / 锁屏时键鼠失效

出现那个全屏的蓝色（或黑色）UAC 提权提示、或者锁屏界面时，钩子和输入注入都会失效，**鼠标键盘会留在原机器上**。

**这是 Windows 的设计限制，任何用户态程序都绕不过去**，不是本程序的 bug。处理办法就是：遇到提权窗口时直接用本机的键盘鼠标。

同理，`Ctrl + Alt + Delete` 属于 Windows 安全序列，也无法转发。

### 8.8 其他

- **想让程序开机就跑起来**：见[部署与安装](部署与安装.md)的「开机自动启动」一节（程序里的「程序启动时自动开始共享」只管共享，不管开机启动）。
- **中文输入法/候选框**：输入法状态是每台机器各自的，切到副机后用的是副机的输入法。
- **剪贴板内容不跨机**：第一版不支持剪贴板共享和文件拖拽，接口预留了但未实现。

## 9. 已知限制

- **只支持单显示器**。多显示器的接口预留了，第一版未实现。
- **剪贴板共享、文件拖拽**：接口预留，第一版未实现。
- **UAC 安全桌面 / Ctrl+Alt+Delete 期间**键鼠会留在原机器上（Windows 限制）。
- **Windows 7 上 DPI 感知只能做到系统级**，不做每显示器 DPI；如果副机是 Win7 且缩放过，接缝高度可能要用手动偏移补偿。
- **需要管理员权限**：每次启动都会弹 UAC，这是全局钩子和输入注入的硬性要求。
